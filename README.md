# 🚀 CS-Algorithms-Demystified

Welcome to **Algorithms Demystified**! This repository is built by high school computer science students, *for* high school computer science students. 

Algorithms can seem intimidating, but they are really just step-by-step recipes for solving problems. This repo breaks down the most important foundational algorithms into bite-sized, easy-to-understand pieces.

---

## 📖 What's Inside?

We’ve organized the algorithms by category so you can find exactly what you need. Each folder contains the code, line-by-line comments, and a simple explanation of how it works.

* **🔍 1. Searching:** Finding what you need fast (Linear Search, Binary Search).
* **🗂️ 2. Sorting:** Putting things in order (Bubble, Selection, Insertion, Merge Sort).
* **🔁 3. Recursion & Math:** Functions that call themselves (Fibonacci, Factorials, Euclidean Algorithm).
* **🗺️ 4. Graphs & Grids:** Pathfinding and maze solving (Breadth-First Search, Depth-First Search).
* **🔐 5. Strings & Crypto:** Puzzles and encryption (Caesar Cipher, Palindromes).

---

## 🛠️ How to Use This Repository

1.  **Pick a Category:** Browse the folders above to find the algorithm you want to learn.
2.  **Read the Readme:** Each algorithm folder has its own mini-README explaining the concept with a real-world analogy.
3.  **Run the Code:** Open the source code files (e.g., `.java`) in your favorite IDE. Play around with it, change the variables, and break things—that's the best way to learn!
